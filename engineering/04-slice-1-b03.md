# 04 — Slice 1 acceptance (benchmark B03)

**Goal:** End-to-end deterministic investigation for **b03** (database connection exhaustion) per [docs/21-benchmark-incidents.md](../docs/21-benchmark-incidents.md).

## Preconditions

- `fixtures/b03/` generated by `scripts/build_fixture.py` from `scenarios/b03/definition.yaml`
- `CONNECTOR_MODE=fixture`, `FIXTURE_ROOT` points at repo fixtures root

## Functional acceptance

1. `POST /api/v1/investigations` with `benchmark_id: b03` and signal from alert → **201**
2. `POST .../run` → **200**, state `rca_candidate`
3. `GET ...` returns:
   - ≥ 4 evidence items (alert, logs, metric, deployment themes)
   - ≥ 1 hypothesis (H1 deployment/config → exhaustion)
   - `rca.status` = `probable`
   - `rca.claims[]` each with non-empty `evidence_ids`
4. Event log includes connector, evidence, hypothesis, and `rca.published` types per [02-investigation-event-catalog.md](02-investigation-event-catalog.md)
5. Runtime never opens `ground_truth.json` (see enforcement in hld/04)

## Golden test tolerances

Compare API aggregate (normalized) to `tests/golden/b03_expected.json`:

| Field | Rule |
|-------|------|
| `rca.status` | Exact: `probable` |
| `rca.root_cause` | Contains substring `connection pool` (case insensitive) |
| `evidence` count | `>= 4` |
| `hypotheses[0].statement` | Contains `deployment` or `configuration` |
| Evidence ids | Stable prefixes `ev_b03_*` per playbook |

Compare eval metrics to `ground_truth.json` separately in `tests/eval/` (optional Phase 0b).

## Idempotency

Second `POST .../run` → **409** `investigation_already_run` (see [lld/08-errors-and-idempotency.md](lld/08-errors-and-idempotency.md)).

## Done when

- Golden test green
- Contract tests pass including B03 examples in OpenAPI
- Manual: `curl` flow documented in root README (Phase 0b)
